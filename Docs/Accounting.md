# 计算与迁移

## 两类事件

购买保存人民币实际投入 `amountCNY`、实际净到账 BTC `receivedSats`、到账账户 `toAccountID`；`amountSats` 与 `receivedSats` 相等。转移从 `fromAccountID` 扣除 `amountSats`，向 `toAccountID` 加入 `receivedSats`，损耗为二者之差。到账不得超过转出，账户不得相同，历史来源余额不得不足。

```text
累计投入人民币 = 所有购买的 amountCNY 之和
累计购买 BTC = 所有购买的 receivedSats 之和 / 100,000,000
累计损耗 BTC = 所有转移 (amountSats − receivedSats) 之和 / 100,000,000
总持有 BTC = 累计购买 BTC − 累计损耗 BTC = 各账户余额之和
综合成本 ¥/BTC = 累计投入人民币 / 总持有 BTC
当前市值 = 总持有 BTC × BTC 人民币参考市价
总盈亏 = 当前市值 − 累计投入人民币
总盈亏率 = (总盈亏 / 累计投入人民币) × 100%
```

BTC 使用 Int64 satoshi，人民币使用 Foundation Decimal；显示舍入不修改原值。零持有时成本、零投入时盈亏率显示「—」。代码返回盈亏比率，由显示层格式化为百分数。

记录按日期时间、sequence、UUID 重放。`calculate(..., asOf:)` 只累计截止时间已发生的事件，`history` 提供逐事件状态及阶梯成本线。编辑、删除、导入均验证完整历史，禁止账户透支。

## 旧版迁移

新版不保存 USDT、手续费、卖出或成本池字段；旧字段仅由私有迁移读取结构识别。

- 人民币购买保留原净到账 BTC，投入为原 `amountCNY + feeCNY`，不重复扣 BTC 费用。
- 转移保留原转出、净到账和账户，损耗自动计算；无法归属购买的额外成本进入报告。
- 无调整或卖出干扰、起始中间余额为零的一对一人民币资金链可合并为购买。非末尾链须全部用尽；末尾唯一购买剩余中间资金按新口径计入该次转换成本，BTC 净到账不变。
- 多笔资金、分批购买、卖出、独立费用、余额调整或来源不明等有歧义记录不迁入统计，报告注明原因；不能由此猜造后续转移的 BTC 来源。

保留购买 ID、日期、录入顺序、账户 UUID，并记录资金来源与购买记录的映射。可明确对应的账户命名为欧易 / 自有钱包，其他必要旧账户保留。

读取旧账本不立即改写。完整验证后先保存原始字节到 `ledger.before-upgrade-vN-UUID.json`，再写 schema 4；导入旧 JSON 也独立保留原始来源。读取失败保留原文件，外部修改冲突拒绝覆盖。JSON 是完整恢复备份，CSV 仅供查看历史。
