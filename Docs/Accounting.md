# 人民币本位计算规则（备份版本 2）

固定本位币 CNY，固定口径 `cny-principal-moving-average-v1`。这是个人实际人民币本金管理账：BTC 与 USDT 互换只结转本金；真正收到人民币时才计算兑现盈亏。它不是税务成本法，也不是以成交时市价重置本金的交易盈亏报表。USDT 只是购币资金的单一中间余额，不增加多币种投资组合或多账户 USDT 系统。

所有页面、编辑、删除及恢复通过同一个 `LedgerEngine` 从完整历史重放。账户余额不是另一份可手工修改的数据。除最后余额外，历史每个时点也必须有足够余额。

## 数量与精度

- BTC：`Int64` satoshi，1 BTC = 100,000,000 satoshi，不经过 Double。
- USDT：Foundation `Decimal`，最多 8 位小数；不假设 USDT 等于 USD，也不以当前汇率回填历史。
- 实付、实收人民币及人民币手续费最多 2 位小数；手工 BTC/CNY 历史单价最多 8 位。
- 人民币成本分摊与费用等值保留 12 位，银行家舍入。显示金额通常 2 位，不把显示结果写回账本。
- 分摊时只舍入本次移出的成本，剩余成本通过减法保留；全部用尽时移出全部剩余成本，不留下尾差。
- 排序为日期时间、同时间的 sequence、UUID。任何记录修改后都按相同顺序重算。
- 负数、过量小数、未知账户、溢出、任何历史余额不足均拒绝保存；候选历史失败不会改变原账本。

## 每种操作的字段和成本流向

### 人民币买 USDT

`amountCNY` = 实际支付人民币总额（**含人民币手续费**）。`receivedUSDT` = 实际到账 USDT（**已扣 USDT 手续费**）。

累计投入和 USDT 本金都增加实际支付人民币；USDT 数量增加净到账。手续费已经包含在总支出中，费用统计不会再加一次本金。USDT 内扣手续费只影响毛购入数量和费用统计，不扣已有 USDT。

### USDT 买 BTC

`settlementCurrency = usdt`，`amountUSDT` = 账户实际扣除 USDT 总量（**含 USDT 手续费**），`amountSats` = 净到账 BTC。原始 `amountCNY = 0`；人民币金额从成本链计算，不要求重复填写。

```text
本次转入 BTC 的人民币本金 = 扣款前 USDT 本金 × 总扣除 USDT ÷ 扣款前 USDT 数量
剩余 USDT 本金 = 原本金 − 本次结转本金
```

USDT 减少总扣款，BTC 增加净到账。累计人民币投入不变。BTC 内扣费用已经包含在净到账差额中；若另在外部支付人民币手续费，则这笔现金增加累计投入及 BTC 本金。

### BTC 提币 / 内部转账

`amountSats` = 来源账户实际扣除总量；`receivedSats` = 目标账户净到账；`feeSats = amountSats − receivedSats`。

例：交易所扣 0.00100000 BTC，钱包到账 0.00099800 BTC，总 BTC 只减少 0.00000200 BTC。转账不算买卖，不增加购买数量和人民币投入，不减少持仓本金；费用由剩余 BTC 承担。历史显示的转出资产本金只是说明本次涉及数量的本金，不是处置或新投入。

支持无 BTC 差额而在外部支付人民币手续费的转账；额外人民币费用增加投入及 BTC 本金。一条记录仅一种手续费币种，多种费用使用独立费用记录。

### BTC 卖回 USDT

`amountSats` = 成交 BTC（**不含额外 BTC 手续费**）；总扣 BTC = 成交量 + feeSats；`receivedUSDT` = 实收 USDT（**已扣 USDT 手续费**）。

```text
移出 BTC 本金 = 卖出前 BTC 本金 × 总扣 BTC ÷ 卖出前 BTC 总量
USDT 增加本金 = 移出 BTC 本金 + 额外支付的人民币手续费
```

BTC 全账户使用同一个平均本金池，与在哪个账户卖出无关。收到的 USDT 获得原本金，不按成交市价建立新成本；此时人民币回款和兑现盈亏都是 0。额外人民币手续费是新的现金投入，USDT 内扣费不再扣原有 USDT。

### USDT 换回人民币

`amountUSDT` = 总扣 USDT（**含 USDT 手续费**）；`amountCNY` = 实际净到账人民币（**已扣人民币手续费**）。

```text
本次移出 USDT 本金 = 扣款前 USDT 本金 × 总扣 USDT ÷ 扣款前 USDT 数量
本次兑现盈亏 = 实收净人民币 − 本次移出本金
```

累计回款增加净到账。累计投入不减少；净回款已扣过的费用不再扣一次。不管理人民币现金账户。

### 兼容旧版人民币直接买 / 卖 BTC

不虚构 USDT 中间过程。买入 `amountCNY` 仍是**不含另填人民币手续费**的购币本金，BTC 为实际净到账；投入和 BTC 本金增加购币金额 + 人民币手续费。卖出 BTC 数量不含额外 BTC 费，人民币为净实收，立即计算净回款减分摊本金的兑现盈亏。消费可选人民币实收 0，确认所消耗本金损失。

### 其他手续费

- BTC：扣指定账户 BTC，同币种剩余持仓承担本金；该池全部耗尽时剩余本金转已实现损失。
- USDT：扣单一 USDT 余额，同币种剩余余额承担本金；全部耗尽时剩余本金转已实现损失。
- 人民币：沿用原版规则，增加外部投入；有 BTC 时加入 BTC 本金，没有 BTC 时记已实现费用损失。取得 USDT 的人民币费用应填在「人民币买 USDT」的总实付和手续费中。
- 「已兑现盈亏」也包含直接消费和最后资产被费用耗尽的本金损失，详情和规则明确这一例外；不会凭行情产生人民币收益。

## 费用人民币等值和换算依据

每条记录保存原始币种、数量和 `feeValuationSource`。BTC 的 feeSats 可无损换算 feeBTC；USDT 保存 feeUSDT；人民币保存 feeCNY。

- `manualPrice`：保留用户当时填写的 BTC/CNY `feePriceCNY`，费用等值 = BTC 费用 × 该价。编辑其他历史不会改变快照。
- `costBasis`：自动按本次成本链估值，原始 feePriceCNY 为 0，计算后的单位成本和等值保存于备份 `entryValuations`。不是历史市场行情；编辑前序交易会重算。
- BTC 买入内扣费使用本次获得 BTC 的人民币本金 ÷ 毛 BTC；BTC 卖出、提币、独立费用使用扣款前 BTC 本金均价。
- USDT 买入内扣费或卖 BTC 所得 USDT 的内扣费，使用本次取得 USDT 的本金 ÷ 毛 USDT；USDT 扣款费用使用扣款前 USDT 本金均价。
- 费用等值仅用于统计。已经包含在扣款或净到账中的费用不能再加到持仓本金。
- CNY 费无需换算。新录入 USDT 费自动按成本链估价，不要求额外汇率输入。

每笔 `EntryValuation` 包含 costCNY（取得/移出/涉及的本金）、feeCNYEquivalent、feeUnitCostCNY；备份同时保存原值和派生快照，恢复必须与完整重算一致。原币数量、换算依据和现金口径足以在脱离 App 后重建账本。

## 持仓首页、USDT 与卖出页面

| 指标 | 口径 |
|---|---|
| 累计投入（成本统计依据） | 实际外部人民币支出；不含 USDT→BTC 或 BTC→USDT 的内部结转 |
| 累计回款（卖出页） | BTC 或 USDT 真正兑回的净人民币 |
| BTC 持仓成本 | 当前 BTC 所分摊的原始人民币本金，含已资本化费用 |
| BTC 当前价值 | BTC 数量 × 最近成功获取的 BTC/CNY 参考行情 |
| 持仓浮动盈亏 | BTC 当前价值 − BTC 持仓成本 |
| 持仓收益率 | 浮动盈亏 ÷ BTC 持仓成本 |
| 实际 BTC 成本价 | BTC 持仓成本 ÷ 当前 BTC 数量 |
| 平均买入价格 | 累计买入本金 ÷ 累计毛购买 BTC；USDT结算本金来自成本链，排除本次单列交易费用，但保留此前取得USDT的成本，因此不是交易所成交市价 |
| USDT 人民币成本 | 单一 USDT 余额的剩余本金，**不是实时市值** |
| 每 USDT 平均人民币成本 | USDT 剩余本金 ÷ USDT 数量 |
| 费用占比 | 累计费用人民币等值 ÷ 累计投入；同时保留 BTC 和 USDT 费用累计数量 |

首页只聚焦 BTC 持仓数量、成本、市值、浮动盈亏金额 / 收益率和费用。点击总 BTC 数量展开具体位置，默认不显示账户明细。「卖出记录」页独立显示累计回款、已兑现盈亏，以及卖 BTC 和 USDT 换回人民币的操作与记录。

分母为 0 显示「—」。没有行情不伪造市值。不会把 USDT 剩余本金加到 BTC 市值后冒充全部资产实时市值。

每步检查本金衔接：

```text
BTC 剩余本金 + USDT 剩余本金 = 累计投入 − 累计回款 + 累计已实现盈亏
所有 BTC 账户余额之和 = 当前 BTC 总量
```

### 验收示例

1. ¥720 买 100 USDT，用 60 USDT 买 BTC：BTC 本金 ¥432，剩余 40 USDT 本金 ¥288，累计投入仍 ¥720。
2. ¥700 买 100 USDT，全买 BTC 后卖回 120 USDT：USDT 本金仍 ¥700，未兑现人民币收益。再用 60 USDT 买 BTC，BTC 分摊 ¥350；剩余 60 USDT 本金 ¥350，兑回 ¥420，兑现收益 ¥70。

## 修改、迁移和备份

编辑或删除早期交易会重算后续两类资产的成本、自动费用折算及历史展示；历史手工行情保持原值。任何时点余额不足阻止保存。

版本 1 的人民币直接交易读取后升级为版本 2 内存模型；首次写回之前，在同一协调写操作内先将原文件字节保存为 `ledger.before-upgrade-v1-UUID.json`。读取本身不改原文件。所有新备份注明 CNY 和固定成本口径。未知版本、错误口径、被篡改的快照、损坏 JSON 都拒绝。每次保存还有 previous 副本，导入替换前另留 before-import 副本。

CSV 是完整历史的阅读/迁移格式，JSON 是恢复格式。有历史的零余额 BTC 账户删除后归档，原始身份和记录仍保留。自动测试只用合成数据。
