# 本地架构

- **LedgerCore**：两类事件模型、Decimal / satoshi、当前与历史重放、备份迁移、文件保存、历史购买汇率、公共分钟 / 日行情读取及 17 种周期聚合。
- **BitcoinLedger**：SwiftUI 窗口、购买 / 转移表单、历史列表、覆盖面板与 Charts 图表。AppStore 先验证候选账本，购买按已可用历史汇率换算并检查取消及并发修改，保存成功才更新界面。日期使用原生 NSDatePicker 支持小时和分钟。
- **依赖**：Apple SwiftUI、AppKit、Foundation、Charts、Swift Testing；SwiftPM 管理构建，无第三方依赖。

账户展开继续使用 Dashboard 原有 `showLocations` 与同一 Button。总持有、动作和指标合并成紧凑顶栏，指标按名称 / 数值两行排列，盈亏使用绿正红负，拖动顺序仅存本机 UserDefaults；图表填充剩余高度。默认窗口 1100×800 一屏显示，最小 600×420 保留可读控件并允许滚动。展开图幅时允许滚动；同一图表实例保留周期与时间窗。覆盖面板禁用背景、固定标题和底栏、滚动内容；取消 / 关闭 / Esc / 外部点击丢弃草稿，保存失败保留草稿。

LedgerRepository 串行使用 NSFileCoordinator、原子替换和读取字节冲突检测。目录 0700，账本及备份 0600；升级与导入先保留原始副本，读取失败不会用空账本覆盖原文件。

实时美元价格保存在账本文档。美元日、分钟和其他盘中周期使用独立缓存，不读取旧人民币缓存。最近分钟优先 Yahoo 并用 Coinbase 补真实 OHLC；其他或较旧盘中窗口从 Coinbase 分页请求。未覆盖的时间窗在交互停稳后加载；已有覆盖只读缓存，历史数字不触发请求。批量 Canvas 绘制市场行情，历史数字变化不重建市场图。默认纵轴适配可见行情、成本与事件，手动调整价轴后保留独立价格窗口；横轴刻度按窗口时长及 UTC 锚点生成，平移不改变比例。取消后的旧请求不发布缓存或错误，待切换来源由独立任务接续。公共行情请求不包含账本信息。来源及失败降级规则见 [PriceAPI.md](PriceAPI.md)。

构建脚本在系统临时目录组装应用，ad-hoc 签名并严格校验后输出 ZIP，避免 Documents 文件提供器附加元数据破坏签名。安装位置为 `/Applications/Bitcoin Ledger.app`。
