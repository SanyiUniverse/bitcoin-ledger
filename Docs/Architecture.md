# 本地架构

- **LedgerCore**：事件模型、Decimal / satoshi 计算、历史重放、迁移备份、持久化、购买汇率与公共行情。
- **BitcoinLedger**：SwiftUI 窗口、表单、历史列表及图表；AppStore 协调验证、换算、保存和行情更新。
- **依赖**：Apple SwiftUI、AppKit、Foundation、Charts、Swift Testing；SwiftPM 构建，无第三方依赖。

## 界面

总览左侧显示持有和购买 / 转移，按钮旁先显示成本金额，后接小号「总成本」。右侧市值、浮盈、浮盈率为三等宽列，沿用 UserDefaults v2 排序，过滤固定位置的成本。盈亏绿正红负。

宽窗市价 / 刷新与损耗 / 占比横排在主指标下方，与左侧动作处于同一底行；宽度不足时两组分行，每组仍横排。正常窗口一屏显示；窄窗、展开钱包或图幅时可滚动，图表填充剩余高度。

图表头部按标题 / 周期、摘要、动作 / 图例分三列；窄窗重排同一子视图，保留图表实例、周期和时间窗。市场行情用 Canvas 批量绘制，历史摘要变化不重建市场图，也不请求行情。来源、聚合与缓存规则见 [PriceAPI](PriceAPI.md)。

表单使用原生日期控件，输入到分钟。覆盖面板禁用背景，标题和底栏固定，正文可滚动；取消、关闭、Esc 或外部点击丢弃草稿，保存失败保留草稿。

侧边栏页面顺序独立保存在本机偏好中；启动时进入排序首项。每日盈亏左明细、右曲线共用一个选中日期：点击明细定位曲线，图内选择驱动列表滚动。左行点击不移动列表，连续或双击不会误选邻行。行情缺失的日期仍能定位，但不绘制虚构价格点。

每日固定时刻来自首笔购买的北京时间，历史金额和购买记账标色由原始交易派生。AppStore 按账目与固定行情版本、最近已结束结算时刻缓存历史结果；当前报价、悬停和提示更新不重放账目。每日曲线在一次绘制中共用可见点和价轴，BTC 成本及事件图层共用一次历史重放。固定格式的界面金额、日期与单次 CSV 导出复用格式器。

## 保存

AppStore 验证候选账本后再保存；购买换算检查取消和并发修改，保存成功才更新界面。LedgerRepository 串行协调文件访问，使用原子替换和原始字节冲突检测。目录权限 0700、文件 0600；读取失败保留原文件。计算与迁移保护见 [Accounting](Accounting.md)。

原始交易、汇率及固定分钟行情进入 schema 7 完整备份，派生盈亏不重复持久化。旧账本升级前保留原文件。已验证文件的来源版本随字节基线缓存；保存时仍核对磁盘原字节，并严格验证新序列化结果，成功后才发布新基线。每日补算按同一锚点复用目标集合，锚点或导入改变会取消失效任务；当前报价请求与每日请求独立。

## 构建

脚本优先已安装的 macOS 26.5 SDK，也可用 `BITCOIN_LEDGER_SDK` 指定，不修改全局开发设置。测试使用隔离临时目录；打包在系统临时目录组装应用，避免 Documents 元数据破坏签名。应用经 ad-hoc 签名和严格校验后输出 ZIP，临时目录自动清理。

安装位置为 `/Applications/Bitcoin Ledger.app`。ZIP 只含应用；账本和本机排序偏好独立保存。验证结果与边界见 [Validation](Validation.md)。
