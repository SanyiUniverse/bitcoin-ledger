# BTC 美元行情

## 来源与真实性

| 数据 | 来源 | 处理 |
| --- | --- | --- |
| 最新市价 | [Blockchain.com](https://www.blockchain.com/explorer/_api/exchange_rates_api)，`blockchain.info/ticker` 的 `USD.last` | 服务无成交时间，显示获取时间；每分钟自动刷新，总览与每日盈亏共用，手动至少间隔一分钟，失败保留最后成功价格并自动重试。 |
| 每日固定快照 | Coinbase BTC-USD 完整一分钟收盘 | 按首笔购买的北京时间时分秒结算，取目标时刻前最后已结束的一分钟；保存该分钟价格，补算只请求目标短窗，正常缺失不借价。 |
| 日 OHLC | [Yahoo Finance BTC-USD](https://finance.yahoo.com/quote/BTC-USD/)，匿名 chart JSON | UTC 标签为日开始，完整收盘下一午夜才用于历史估值；当日数据截至获取时刻，标为未收盘。无效 OHLC 只保留可靠收盘，null 不转成零价。 |
| 盘中 OHLC | 最近七天 1 分钟优先 Yahoo；缺失、无效或主源失败由 [Coinbase](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-candles) 补取 | 其他盘中周期和较旧窗口直接读取 Coinbase，再聚合目标周期；不插值，不把日 K 拆成分钟 K。 |
| 早期及缺日参考收盘 | [Coin Metrics Community](https://gitbook-docs.coinmetrics.io/packages/coin-metrics-community-data) 的 `PriceUSD` | 无 OHLC，以灰线 / 灰点显示。日标签代表当天日终值，下一午夜才用于历史估值。可靠价格之前留空。 |

Coinbase 来源周期为 60 / 300 / 900 / 3600 / 21600 秒，选择能整除目标周期且不长于窗口的粒度，仅取截止时刻前已结束的来源时段。每页最多 300 个时段，串行限速、边界去重。单次最多 16,000 根目标蜡烛、100,000 个来源时段；超限提示缩短范围或加长周期。无交易或交易所成立前的数据可能缺失，不能承诺任意历史日期都有分钟行情。

每日结算保留首笔购买的分数秒；分钟行情的结束时刻向下取整到整分钟。例如 11:00:17 使用 10:59–11:00 收盘，不请求未来的 11:00–11:01。schema 7 保留旧版 1–6 的资料；旧每日价格或分钟缓存只有来源可靠、完整结束且对应相同分钟时才复用。更正首笔购买时间后，旧任务取消，按新结算时刻补齐对应日期，不把原中午价格移作其他时刻的价格。

市场价格直接使用美元。购买人民币换算单独使用 [Frankfurter](https://frankfurter.dev/) 的 ECB USD/CNY 每日参考率，规则见 [Accounting](Accounting.md)。请求只含固定币种和公共日期，不发送账本金额、账户或持仓，无需 API Key、账户或订阅。

## 周期与历史

周期为 1 / 3 / 5 / 15 / 30 分钟，1 / 2 / 4 / 6 / 8 / 12 小时，日、3 日、周、月、3 月、年。范围与周期独立保留，可自选起止日期；「全部」范围从 2009-01-03 起，无可靠价格的日期留空。

固定周期按 UTC 锚点聚合；周从周一开始，月 / 季度 / 年按自然边界。OHLC 使用首开、最高、最低、末收；缺口、参考收盘或尚未收盘的周期不能标为完整。仅显示与窗口重叠的 K 线，未完成周期只含截至时刻已观测的行情。

摘要默认显示当前账本与最新报价。鼠标移动查看历史，停下约 1.2 秒或移开恢复。历史持有只累计截止前的事件，价格取此前最近可用收盘并注明时间，不借用未来行情或后来的购买 / 损耗。每笔事件改变成本阶梯线。

平移、时间缩放和方向键移动时，自动价格轴适配可见行情、成本及事件。手动拖动右侧价格轴后保留该比例，双击恢复自动；重置、范围或周期切换恢复默认视图。

## 缓存与失败

美元缓存与旧人民币缓存隔离。日缓存四小时有效，最近分钟缓存一分钟有效；日缓存获取时间早于窗口起点时重取。盘中缓存须满足周期、日期覆盖和来源粒度。粒度不足或聚合蜡烛跨越新的历史截止时，重新获取精细来源，不能拆分已聚合的蜡烛；未完成周期仅保留截止前已观测的行情。取消的旧请求不发布数据或错误，HTTP 429 退避。

失败保留缓存及获取时间，但只有匹配周期且覆盖所选窗口的缓存可显示；失败或超限不以旧图代替新选择。空窗口提示缺行情，无数据时显示错误，不能用今天价格回填；参考源失败时仍可显示现代日行情。匿名来源可能修正或缺失数据，参考收盘始终与真实 OHLC 区分。

暂时网络故障、HTTP 408 与 5xx 使用 60 / 120 / 240 / 480 / 900 秒退避，HTTP 429 从 120 秒起并尊重 Retry-After。提示逐秒递减，到点自动联网重试，不因新鲜缓存而跳过请求。切换图表选择取消旧任务；最新范围继续跟随当前时间，固定历史范围保持日期。无效范围、正常历史缺失和无效响应不无限重试。休眠恢复最多立即补一次到期重试。
