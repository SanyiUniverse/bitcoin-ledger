## 优化核对

- 每日派生缓存只在交易、账户、固定行情或已结束结算时刻变化时失效；当前报价、普通时钟刷新不重放历史。编辑、导入、时间回拨和失败保存均有隔离检查。补齐期间按最新账本合并，历史目标集合只生成一次。
- 每日图每次渲染共用点集、可见行、纵轴与符号大小，避免每个点重扫全部历史；BTC 成本线与交易事件共用一次账本重放，输出边界与旧接口等价。固定日期、金额及 CSV 格式器复用，逐字节输出回归通过。
- 存储继续只保存行情依据，金额由账本派生。保存仍校验候选 JSON、检测原始文件字节冲突并原子落盘；仅复用已验证且字节一致的原版本信息，损坏文件、恢复与失败后重试均有回归检查。
- 合成基准：4,000 笔交易 / 2,001 天，单次直接派生约 40.93 ms，热缓存读取约 0.002 ms，2,000 次缓存读取未新增派生；2,000 行曲线重复扫描约 1,480.70 ms，共用渲染结果约 1.42 ms，点计数一致；3,000 个 CSV 时间格式化约 258.04 ms → 2.65 ms，文本相同。这些为对应片段的本机计时，不代表整页或整次保存的加速倍数。

## 边界

测试只使用隔离合成账本，不向正式账本写入测试记录。真实账本、截图和本机缓存不提交到仓库；应用更新保留独立账本存储。

最终原生报告的 `SCOPE` 明确：隐藏 `NSHostingView` 不暴露部分纯 SwiftUI 工具条、明细按钮、侧边栏正文与拖动注册。安装版补充验证了实际控件点击、双击、图表选点、五个导航按钮与首项启动；排序规则和手势由原生回调、隔离渲染验证。物理触控板捏合及完整拖动手势未独立实测。
