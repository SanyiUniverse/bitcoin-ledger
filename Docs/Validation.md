## 已执行运行检查

- Release 可执行文件成功在本机启动；独立测试数据目录避免污染正式账本。
- 首次运行公共 API 成功返回 BTC/CNY，并写入本地最后成功价格；没有预置持仓。
- 应用层追加 **10 项检查通过**：调用生产 `AppStore` 创建 3 账户及 6 条合成记录，执行新增、修改、删除、账户删除、关闭后重新读取，核对 Dashboard 快照、成本与行情缓存。最终总量 279,690 satoshi，账户余额之和一致。
- 用生产视图源码和合成账本渲染并检查总览、历史、账户、买入编辑、转账编辑共 5 个原生视图；文字、数量、费用字段和按钮布局可读。这是 `NSHostingView` 的独立离屏渲染，不是实际运行窗口截图。
- `/Applications/Bitcoin Ledger.app` 安装后通过 `codesign --verify --strict`；交付 ZIP 解压后也通过严格签名检查。可执行文件为 arm64，仅依赖系统框架。

## 未完成的界面验收

原生自动点击工具在读取 Bitcoin Ledger 的 SwiftUI 窗口时发生自身崩溃（SkyComputerUseService 的 Array.remove 越界），应用本身仍运行且行情请求成功。重启工具、安装到标准目录并重新启动后仍复现。没有以其他键鼠/辅助功能脚本绕过工具。

因此，**真实窗口中的逐项点击、系统导入导出文件面板、菜单及完整交互验收没有完成**。54 项自动测试、10 项应用层检查和 5 个视图渲染不能替代这部分验收；此限制在交付时明确说明。

## 适用范围

本次平台为 Apple Silicon、macOS 26.7、Swift 6.4、macOS 26.5 SDK。代码最低部署目标 macOS 14，但没有在其他系统版本或 Intel Mac 上运行验证。V1 是本机个人使用版本，未做 Apple Developer ID 公证。外部行情无 SLA；离线时保留缓存。
